# PPT精细化还原与组件重构流程

用于已有PPT页面重做、参考图高度还原、系统成果展示页制作等场景。

## 一、页面拆解阶段

在进入PPT编辑前，不直接制作整页图片，先拆解页面：

1. 页面结构
- 标题区
- 说明文字区
- 主视觉区
- 功能模块区
- 底部流程/总结区

2. 素材类型
- 真实系统截图：必须来源于用户资料，不得用AI生成界面替代。
- 表格类素材：单独重构为PPT表格组件。
- 图表类素材：使用PPT图表、形状和文本重新制作。
- 流程类素材：使用形状、箭头、节点组件重建。
- 复杂图片：作为独立图片素材插入。

## 二、素材核验原则

- 每张图片确认来源和用途。
- 系统截图优先使用真实资料。
- 不得为了填充版面新增不存在的数据、案例、指标或系统功能。
- 真实成果页面中的数字、项目名称、评价结果必须能追溯到资料来源。

## 三、页面重构原则

参考图中的：
- 标题字体
- 字号层级
- 蓝白色彩体系
- 卡片边框
- 表格样式
- 图标布局
- 间距关系

应尽量一比一还原。

禁止：
- 将整页参考图直接作为背景。
- 将本应编辑的文字、表格、流程制作成图片。
- 使用低清截图替代高清素材。

## 四、应用实例页制作模板

应用实例页优先采用：

业务流程链 → 系统界面展示 → 数据/结果表达 → 应用价值总结

其中：

- 主界面区域：真实系统截图。
- 业务流程：PPT形状流程。
- 数据展示：可编辑表格或图表。
- 应用效果：基于资料支撑的总结卡片。

## 五、逐页制作流程

1. 参考图确认
2. 页面结构拆解
3. 素材清单建立
4. 真实图片核验
5. 图表/表格组件重构
6. PPT组件组装
7. 渲染检查
8. 根据反馈迭代

## 六、质检重点

检查：

- 是否复用了已确认素材。
- 是否存在杜撰数据。
- 是否保持参考图视觉体系。
- 是否所有文字、形状、表格可编辑。
- 是否存在图片裁剪不合理、清晰度不足、信息缺失问题。
