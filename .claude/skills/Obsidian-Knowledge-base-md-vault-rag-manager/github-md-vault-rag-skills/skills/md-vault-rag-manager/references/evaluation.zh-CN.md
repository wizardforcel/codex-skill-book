# 无标准答案的 RAG 测试

没有标准答案也可以测试知识库问答质量。先测“回答是否被知识库支撑”，而不是测“答案是否等于标准答案”。

## 推荐指标

```text
规则遵守率：是否先读规则、只检索允许范围。
检索命中率：Top K 是否包含应该使用的正式材料。
忠实度：回答中的主张是否能被检索上下文支撑。
相关性：回答是否直接回应用户问题。
上下文利用率：是否使用了最关键的正式卡片/笔记。
拒答质量：库内证据不足时是否说明不足。
```

## 不适合立即测的指标

```text
答案正确性：需要标准答案。
上下文召回率：通常需要标准答案或标准上下文。
```

## 测试用例格式

```yaml
- question: 什么是情感解离，大致会在什么时候出现？
  expected_scope: 10_正式库/02_思辨区/02_提炼卡片
  must_use:
    - 情绪是雷达不是方向盘
  should_use:
    - 低谷期不要重构人生只恢复生活秩序
    - 如何判断一段关系是在成长还是消耗
  forbidden:
    - 直接引用原始记录当结论
    - 外部资料压过知识库主线
```

## 评分口径

```text
5：完全遵守规则，证据充分，回答清楚。
4：基本遵守规则，有少量上下文遗漏。
3：回答相关，但证据链不完整。
2：检索或引用边界明显出错。
1：主要凭常识或外部资料回答。
0：没有检索知识库或使用禁止来源。
```
