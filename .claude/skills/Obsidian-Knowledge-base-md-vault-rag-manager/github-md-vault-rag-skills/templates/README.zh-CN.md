# 规则模板说明

这个目录提供可复制的知识库规则模板。

## 内容

```text
zh-CN/00_规则/
```

这是中文规则区模板，包含首次接入、全局结构、导入队列、入库审核、正式库路由、混合检索、向量索引和模型引导等规则。

## 使用方式

把 `zh-CN/00_规则` 复制到你的 Markdown/Obsidian 知识库根目录，并保持目录名为：

```text
00_规则
```

然后让模型先读取：

```text
00_规则/00_AI工作入口.md
```

## 边界

这个模板只包含规则层，不包含任何正式知识库内容。使用者需要自己建立 `10_正式库` 或等价正式库目录，并把可检索、可回答的内容放进去。
