# 导入材料与队列规则

路径表示阶段，标签表示动作，frontmatter 表示路由。

## 1. 导入入口

```text
01_导入原始材料/
  项目/
  非项目/
```

规则：

```text
项目材料放进 01_导入原始材料/项目
非项目或不确定材料放进 01_导入原始材料/非项目
```

`项目` 下的所有材料默认继承项目语义，不需要每个文件单独改名。

## 2. 处理队列

```text
02_入库处理区/
  01_整理报告/
  02_入库候选/
  03_待归类/
```

含义：

```text
01_整理报告：AI 对导入材料的判断、风险、建议。
02_入库候选：AI 已做成最终格式，等待你打标签。
03_待归类：你已经允许入库，等待 AI 移动到最终文件夹。
```

## 3. 流转

```text
01_导入原始材料
-> 02_入库处理区/01_整理报告
-> 02_入库处理区/02_入库候选 + #入库/待确认
-> 你改成 #入库/允许 或 #入库/拒绝
-> #入库/允许 进入 02_入库处理区/03_待归类
-> #入库/拒绝 进入 99_垃圾区
-> 待归类材料按 route_target 进入 10_正式库
```

## 4. AI 处理范围

导入处理时，AI 只看：

```text
01_导入原始材料
02_入库处理区/02_入库候选
02_入库处理区/03_待归类
```

除非查重、补来源或补双链，才读取 `10_正式库` 中的相关材料。
