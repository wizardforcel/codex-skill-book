# 笔记区规则

这是 `10_正式库/01_笔记区` 的区域规则。规则文件统一存放在 `00_规则`，本文件只保留笔记区特有的导航和入库要求。

## 1. 区域定位

笔记区用于存放已经可以入库的普通笔记、工作实践、思维架构和长期维护内容。

当前子区域：

```text
工作实践/
思维架构/
```

AI 进入笔记区时，先读：

```text
10_正式库/01_笔记区/00_笔记区索引.md
10_正式库/01_笔记区/00_笔记区状态.base
```

## 2. 检索边界

进入笔记区时，应先限定路径：

```text
10_正式库/01_笔记区
```

再按 `00_规则/06_AI调用过滤与标签检索规则.md` 的标签和 frontmatter 条件过滤具体文件。

## 3. 入库要求

正式调用前，笔记应尽量具备：

```text
type
status
truth_status
area
summary
source
source_quality
usable_for
aliases
keywords
last_reviewed
last_verified
valid_until
tags
```

如果没有这些字段，AI 可以作为普通笔记阅读，但不能默认当成高可信判断。

## 4. 项目知识库

处理 `工作实践/项目知识库` 时，先读：

```text
00_规则/15_项目知识库规则与模板.md
```

项目区内的总索引只负责导航，不负责定义模板。
