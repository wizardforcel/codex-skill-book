# 每日日志规则与模板

本文件定义 `10_正式库/04_每日日志` 的日志写法。日志目录只保留具体日期文件，不再放规则或模板类 README。

## 1. 日志原则

每天结束前只回答一个问题：

```text
如果明天有人问我今天做了什么，我能把什么东西甩到他面前？
```

不是“我想明白了什么”，而是“我做完了什么”。

核心原则：

```text
交付必须是物理可触摸的：文件、链接、截图、demo，不是观点。
不自我欺骗：想明白不算交付，做出来才算。
60 分就扔：不等完美。
当天记：拖到第二天就模糊了。
```

## 2. 命名规则

```text
10_正式库/04_每日日志/YYYY-MM-DD.md
```

文件名即日期，模板标题中的日期与文件名保持一致，周几可省略不写。

## 3. 日志模板

```markdown
---
type: daily_log
status: reviewed
truth_status: self_confirmed
area: 每日日志
summary:
date: YYYY-MM-DD
last_reviewed: YYYY-MM-DD

  - 日志/每日
```
