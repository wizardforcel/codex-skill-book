# 全局结构与阶段规则

这个库的核心链路：

```text
导入原始材料
-> AI 整理
-> 垃圾鉴别
-> 入库候选
-> 人工标签放行
-> 待归类
-> 正式库
-> 后续 AI 调用
```

## 1. 文件夹职责

```text
00_规则：全库唯一规则区。
01_导入原始材料：懒人投喂入口，只区分项目和非项目。
02_入库处理区：AI 工作队列，不是正式知识库。
10_正式库：唯一正式库。
99_垃圾区：拒绝入库、鉴别失败、污染性内容。
```

## 2. 人和 AI 的分工

```text
你负责：判断候选内容是否允许入库。
AI 负责：整理、鉴别、生成候选成品、补字段、补链接、按规则移动。
```

## 3. 正式库当前状态

```text
10_正式库/01_笔记区：可作为正式入库区域。
10_正式库/02_思辨区：仍需按标签、frontmatter 和提炼状态区分可信度，默认不整体作为可信知识调用。
10_正式库/02_思辨区/00_思辨MOC：思辨区的 Obsidian 导航和 MOC，不是全库规则。
```

如果思辨区内某个文件已经补齐格式，并带有：

```text
#入库/已入库
#归类/已归类
truth_status: self_confirmed
```

它才可以被后续 AI 当作正式知识调用。
