# 项目知识库规则与模板

本文件定义项目类材料如何写成项目知识库。模板类文件统一放在 `00_规则`，项目目录里只保留项目正文、附件索引和项目总索引。

## 1. 适用场景

```text
项目源码
项目说明文档
作品集项目
部署材料
工具或业务系统复盘
```

项目材料先进入入库候选，不能绕过垃圾鉴别和人工闸门。

## 2. 推荐目录

```text
项目知识库/
  00_项目知识库总索引.md
  项目名称/
    项目名称.md
    附件索引.md
    assets/
```

总索引负责导航，不定义规则。项目模板以本文件为准。

## 4. 附件规则

```text
小项目：附件放项目同目录的 assets/。
大项目：按 images/、docs/、exports/、code/ 分层。
图片、PDF、截图、导出物、原始文件都算附件。
附件入口写到项目主页和附件索引，不把素材混进正文。
```

如果项目笔记经常移动，优先使用同目录或同目录子文件夹，减少链接断裂。

## 5. 写作边界

```text
项目介绍：写给人看。
附件：保存证据和原材料。
任务与进度：服务执行。
关键决策：服务复盘。
风险与待办：服务后续继续做。
交付物：服务对外展示。
```

模板只规定展示结构，不替用户决定公开边界、作品集口径或最终可信状态。
