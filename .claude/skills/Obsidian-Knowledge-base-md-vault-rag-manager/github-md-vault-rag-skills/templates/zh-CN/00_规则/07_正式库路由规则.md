# 正式库路由规则

正式库只有一个：

```text
10_正式库/
```

正式库内部再分类。

AI 进入正式库时，必须先读取：

```text
00_规则/12_正式库入口规则.md
```

## 1. 当前分类

```text
10_正式库/
  01_笔记区/
  02_思辨区/
  03_项目区/
  04_每日日志/
```

思辨区内部的 `00_思辨MOC` 是 Obsidian MOC/导航层，不是规则文件夹。

## 2. 路由字段

候选成品必须包含：

```yaml
summary:
route_target:
route_reason:
```

示例：

```yaml
route_target: 10_正式库/01_笔记区/思维架构
route_reason: 这是已经可入库的长期笔记材料。
```

## 3. 路由规则

```text
可入库的普通笔记、工作实践、思维架构 -> 10_正式库/01_笔记区
type: note -> 10_正式库/01_笔记区
作品集/复盘/展示型项目知识库 -> 10_正式库/01_笔记区/工作实践/项目知识库
独立项目管理材料 -> 10_正式库/03_项目区
每日交付记录 -> 10_正式库/04_每日日志
未完全核实的思辨材料 -> 10_正式库/02_思辨区
思辨导航、索引、导读 -> 10_正式库/02_思辨区/00_思辨MOC
已鉴别并确认的思辨卡片 -> 10_正式库/02_思辨区/02_提炼卡片
思辨原始对话 -> 10_正式库/02_思辨区/01_思辨记录
思辨项目 -> 10_正式库/02_思辨区/03_Projects
思辨 Areas 材料 -> 10_正式库/02_思辨区/04_Areas
已归档思辨材料 -> 10_正式库/02_思辨区/06_Archive
思辨输出材料 -> 10_正式库/02_思辨区/07_输出池
```

## 4. 完成路由后

AI 必须更新：

```yaml
status: reviewed
truth_status: 保留 source_backed，或改为 self_confirmed（以实际来源为准）
tags:
  - 入库/已入库
  - 归类/已归类
```

并补足：

```text
source
summary
related
usable_for
route_target
last_reviewed
last_verified
valid_until
```

## 5. 无法确定时

不要硬塞进正式库。

保留在：

```text
02_入库处理区/03_待归类
```

并写明需要你确认的问题。
