# 正式库入口规则

这是 `10_正式库` 的区域入口规则。规则文件统一存放在 `00_规则`，进入正式库时先读本文件，再按目标区域读取对应区域规则。

## 1. 正式库结构

```text
10_正式库/
  00_正式库索引.md
  00_检索索引/
  01_笔记区/
  02_思辨区/
  02_思辨区_待整理/
  03_项目区/
  04_每日日志/
```

说明：

```text
01_笔记区：普通笔记、工作实践、思维架构和长期维护内容。
02_思辨区：思辨记录、提炼卡片、MOC 和输出材料的主工作区。
02_思辨区_待整理：历史待整理材料，未完成入库标记前不能作为稳定知识调用。
04_每日日志：每日交付记录，写法以 00_规则/16_每日日志规则与模板.md 为准。
00_检索索引：正式库混合检索生成物，只用于召回候选内容，不是知识正文。
```

## 2. 入口顺序

```text
先读 00_规则/00_AI工作入口.md
再读 00_规则 中的相关底层规则
再读 00_规则/12_正式库入口规则.md
需要混合检索时读取 00_规则/18_混合检索与向量索引规则.md
再按目标区域读取：
  00_规则/13_笔记区规则.md
  00_规则/14_思辨区规则.md
最后按索引、标签和 frontmatter 打开具体文件
```

正式调用的允许和排除条件只以 `00_规则/06_AI调用过滤与标签检索规则.md` 为准，避免区域文件重复维护同一套判断标准。

## 4. 混合检索入口

正式库混合检索索引位于：

```text
10_正式库/00_检索索引/
```

使用规则以 `00_规则/18_混合检索与向量索引规则.md` 为准。索引命中只表示“可能相关”，回答前必须打开原始 MD 并检查 metadata。
