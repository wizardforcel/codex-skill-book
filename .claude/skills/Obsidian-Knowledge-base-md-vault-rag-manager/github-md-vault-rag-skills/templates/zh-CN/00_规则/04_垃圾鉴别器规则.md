# 垃圾鉴别器规则

垃圾鉴别器是导入材料和入库材料之间的防污染层。

## 1. 必须鉴别的内容

```text
AI生成回答
AI总结
AI分析
AI给出的人物画像
AI给出的长期判断
来源不明的二手观点
让人舒服但没有证据的解释
```

## 2. 七项检查

```text
是否有来源？
是否能追溯到你的原始材料？
是否把你没说过的东西强加给你？
是否过度肯定、迎合或谄媚？
是否给出过大、过满、过确定的判断？
是否只是漂亮废话，不能转成行动？
是否和已有高可信卡片冲突？
```

## 3. 处理结果

```text
通过：证据充分，制作候选成品，打 #入库/待确认，等待人工放行。
保留：有启发但证据不足，制作候选成品，在垃圾鉴别结果中标注风险，打 #入库/待确认。
降权：只写入整理报告，不进入核心卡片。
废弃：移入 99_垃圾区。
```

## 4. 默认字段

```yaml
source_quality: ai_generated
status: ai_generated
truth_status: unverified
review: pending
confidence: medium
tags:
  - 入库/待确认
risk:
  - possible_flattery
  - possible_overgeneralization
```

## 5. 硬规则

```text
没有原始来源的 AI 观点，不进入核心卡片。
没有 #入库/允许 的候选成品，不得正式入库。
没有 #入库/已入库 的内容，不得作为后续 AI 判断依据。
truth_status: discarded 的内容不能作为判断依据。
```
