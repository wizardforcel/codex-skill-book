# 入库格式模板

AI 制作候选成品和正式入库文件时，优先使用这些格式。

专项模板见：

```text
项目知识库：00_规则/15_项目知识库规则与模板.md
每日日志：00_规则/16_每日日志规则与模板.md
```

## 1. 候选成品模板

```markdown
---
type:
status: ai_generated
truth_status: unverified
area:
summary:
source:
source_quality:
related:
usable_for:
aliases:
keywords:
route_target:
route_reason:
review: pending
confidence: medium
last_reviewed:
tags:
  - 入库/待确认
---

# 标题

## 核心判断

## 为什么值得记录

## 适用场景

## 不适用边界

## 来源

## 相关卡片

## 垃圾鉴别结果

## 建议入库位置
```

## 2. 正式入库笔记模板

```markdown
---
type: note
status: reviewed
truth_status: self_confirmed
area:
summary:
source:
  - self_note
source_quality: self_note
related:
usable_for:
  - 正式库调用
aliases:
keywords:
route_target:
route_reason:
review: done
confidence: high
last_verified:
valid_until:
conflict_note:
tags:
  - 入库/已入库
  - 归类/已归类
last_reviewed:
---

# 标题

## 核心内容

## 为什么值得记录

## 使用场景

## 来源

## 相关
```

