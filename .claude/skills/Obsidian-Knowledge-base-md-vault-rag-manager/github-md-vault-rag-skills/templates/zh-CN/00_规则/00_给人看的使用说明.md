# 给人看的使用说明

## 1. 这个库怎么用

你只需要把材料放进：

```text
01_导入原始材料/
```

项目材料放：

```text
01_导入原始材料/项目/
```

非项目或不确定材料放：

```text
01_导入原始材料/非项目/
```

## 2. 两种工作模式

默认是人工辅助模式：

```text
AI 先整理成候选，你再决定是否入库。
```

想快速处理时，直接说：

```text
全自动处理
```

全自动模式下，AI 会自行判断、归类、入库或废弃。

## 3. 你需要做什么

人工辅助模式下，你只需要改候选文件里的标签：

```text
#入库/允许
#入库/拒绝
```

其他整理、移动、补字段、建链接，由 AI 处理。

## 4. 去哪里看结果

正式内容看：

```text
10_正式库/
```

项目知识库看：

```text
10_正式库/01_笔记区/工作实践/项目知识库/
```

每日记录看：

```text
10_正式库/04_每日日志/
```

被拒绝或废弃的内容看：

```text
99_垃圾区/
```

## 5. 最重要的规则

```text
00_规则 不放内容，只放规则和说明。
01_导入原始材料 是投喂入口。
02_入库处理区 是临时队列。
10_正式库 才是正式知识库。
99_垃圾区 不能当知识来源。
```

一句话：

```text
材料先丢导入区；想省心就说全自动；想把关就看候选标签。
```
