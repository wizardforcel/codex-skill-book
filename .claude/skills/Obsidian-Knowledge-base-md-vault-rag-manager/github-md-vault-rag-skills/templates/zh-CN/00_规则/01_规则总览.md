# 规则总览

全部规则只放在 `00_规则`。其他区域不再放规则 README，避免 AI 读到重复规则。

## 1. 当前外层结构

```text
00_规则/
01_导入原始材料/
02_入库处理区/
10_正式库/
99_垃圾区/
```

## 2. 正式库结构

只有一个正式库：

```text
10_正式库/
  00_正式库索引.md
  00_检索索引/
  01_笔记区/
  02_思辨区/
  03_项目区/
  04_每日日志/
```

说明：

```text
00_检索索引：正式库混合检索生成物，用于切块、BM25 和向量召回，不是知识正文。
01_笔记区：可以作为正式入库区域使用。
02_思辨区：还需要按标签、frontmatter 和提炼状态区分可信度，默认不整体作为可信知识调用。
03_项目区：项目类正式材料入口，具体模板看 00_规则/15_项目知识库规则与模板.md。
04_每日日志：每日交付记录，写法看 00_规则/16_每日日志规则与模板.md。
```

## 3. 队列结构

```text
02_入库处理区/
  01_整理报告/
  02_入库候选/
  03_待归类/
```

## 4. 规则文件

```text
00_AI工作入口：AI 每次处理前先读。
01_规则总览：全库结构索引。
02_全局结构与阶段规则：文件夹、阶段、整体工作流。
03_导入材料与队列规则：导入区和处理区怎么流转。
04_垃圾鉴别器规则：防止 AI 垃圾污染知识库。
05_入库标签与人工闸门规则：你改什么标签，AI 执行什么动作。
06_AI调用过滤与标签检索规则：正式调用时怎么过滤，如何只在某个文件夹内按标签检索。
07_正式库路由规则：允许入库后文件放到哪里。
08_入库格式模板：候选成品、正式笔记、原始记录、整理报告的统一格式。
09_入库审核.base：入库审核、允许入库、待归类、拒绝入库的 Bases 工作台。
10_全库状态.base：正式可调用、待提炼、待确认、已废弃的 Bases 总览。
11_固定SOP_全库作业流程：AI 每次作业的固定顺序，先按任务类型分流，再进入具体流程。
12_正式库入口规则：正式库入口、区域入口和索引读取顺序。
13_笔记区规则：笔记区定位、检索边界和入库字段要求。
14_思辨区规则：思辨区入口、内容级提炼链路和调用边界。
15_项目知识库规则与模板：项目类材料的目录、主页模板和附件规则。
16_每日日志规则与模板：每日日志的命名、原则和写作模板。
17_知识库建设与检索优化规则：原子化、summary、有效期、AI 检索顺序和向量索引排除规则。
18_混合检索与向量索引规则：正式库混合检索索引范围、切块、向量层和使用边界。
19_模型首次接入与引导生成规则：模型第一次拿到规则区时的自动接入、骨架检查、说明生成和自检流程。
```

## 5. 模板类文件

模板类文件定义“怎么写”，也属于规则，统一放在 `00_规则`。

```text
00_规则/08_入库格式模板.md
00_规则/15_项目知识库规则与模板.md
00_规则/16_每日日志规则与模板.md
```

其他区域不再保留模板类文件。

## 6. 索引类文件

索引、MOC、导读和 Bases 是导航或状态视图，不是规则文件。

```text
索引/MOC/导读：保留在对应内容区域，帮助 AI 缩小范围和进入具体材料。
Bases：保留在对应状态面板位置，读取标签和 properties。
规则文件：只放在 00_规则，定义流程、边界、模板和读取顺序。
```

AI 只要先读 `00_规则`，就能知道下一步该读哪个索引、进入哪个区域、按什么模板写。

首次拿到本库规则时，AI 必须先读：

```text
00_规则/19_模型首次接入与引导生成规则.md
```

再执行初始化、引导生成、内容处理或正式库检索。

## 7. 区域规则

区域规则统一放在 `00_规则`，对应区域入口处不再保留规则类文件。

```text
00_规则/12_正式库入口规则.md
00_规则/13_笔记区规则.md
00_规则/14_思辨区规则.md
```

AI 工作顺序：

```text
先读 00_规则 的底层规则
再读 00_规则 中对应目标区域的区域规则
再按标签/frontmatter 检索具体内容
```

## 8. Bases 视图

Bases 用来自动读取标签和 properties，显示当前状态。你只改笔记里的标签或属性，Bases 会自动刷新视图。

```text
00_规则/09_入库审核.base
00_规则/10_全库状态.base
10_正式库/01_笔记区/00_笔记区状态.base
10_正式库/02_思辨区/00_思辨区状态.base
```

## 9. 混合检索索引

正式库检索索引位于：

```text
10_正式库/00_检索索引/
```

它是生成物，不是规则文件，也不是知识正文。AI 可以用它召回候选内容，但最终回答必须回到原始 MD、frontmatter 和 `00_规则` 判断。
