# 入库标签与人工闸门规则

AI 可以整理材料，但不能替你决定什么是知识。

## 1. 你手动维护的标签

```text
#入库/允许
#入库/拒绝
```

## 2. AI 维护的标签

```text
#入库/待确认
#入库/已入库
#归类/待归类
#归类/已归类
#对话/待提炼
#对话/已提炼
```

## 3. 标签含义

```text
#入库/待确认：AI 已做成候选成品，等待你判断。
#入库/允许：你允许进入知识库，但还未完成最终归类。
#入库/拒绝：你不允许进入知识库。
#入库/已入库：已进入正式库，可被后续 AI 调用。
#归类/待归类：等待 AI 按 route_target 放到最终文件夹。
#归类/已归类：已经放到最终文件夹。
#对话/待提炼：原始思辨记录仍需提炼成卡片、项目或输出。
#对话/已提炼：原始思辨记录已经完成本轮内容级提炼。
```

## 4. 思辨记录提炼状态

原始思辨记录初始状态：

```yaml
type: raw_dialogue
status: raw
truth_status: source_backed
extract_status: pending
tags:
  - 对话/待提炼
```

完成提炼后，AI 应改成：

```yaml
type: raw_dialogue
status: archived
truth_status: source_backed
summary:
extract_status: done
extract_depth: content_level
tags:
  - 对话/已提炼
```

原始记录即使已提炼，也只作为 source 追溯，不直接作为稳定判断。

完成提炼必须满足以下最低标准：

```text
必须读取原始正文，而不是只读取文件名、旧速览或旧索引。
必须写出 summary 和 ## 核心观点，覆盖本文件实际讨论的主要议题。
必须列出可复用判断、可转化去向和污染风险/调用限制。
长对话必须保留议题索引，方便之后追溯到具体段落。
文件级初筛、分类描述、优先级判断，不能单独标记为 #对话/已提炼。
```

## 5. 模板来源

本文件只定义人工闸门和标签流转，不重复维护模板。候选成品、正式入库、思辨记录、整理报告的字段模板统一读取：

```text
00_规则/08_入库格式模板.md
```
