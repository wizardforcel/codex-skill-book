# Rule Template Guide

This directory provides reusable vault rule templates.

## Contents

```text
zh-CN/00_规则/
```

This is the Chinese rules-folder template. It covers first-time onboarding, global structure, import queues, review gates, formal-library routing, hybrid retrieval, vector indexing, and model guidance.

## Usage

Copy `zh-CN/00_规则` into the root of a Markdown or Obsidian vault and keep the folder name as:

```text
00_规则
```

Then ask the model to read:

```text
00_规则/00_AI工作入口.md
```

## Boundary

This template contains only the rule layer. It does not include any formal knowledge-library content. Users must create their own `10_正式库` or equivalent formal-library folder and put retrievable answer evidence there.
