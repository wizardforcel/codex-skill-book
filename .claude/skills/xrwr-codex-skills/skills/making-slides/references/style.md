# スライドの見た目

実際に作って読みやすかったデッキから取り出した規則。

## 色

スライドは白い背景を自分で描くので、Docs の色トークンではなく次の固定色を使う。

| 名前 | 値 | 使い方 |
| --- | --- | --- |
| `N` 紺 | `#1F4E79` | 基調。見出し帯、ピル、矢印、結果ボックス |
| `D` 濃紺 | `#0B1F33` | 表の行見出し、表紙の日付 |
| `R` 赤 | `#D21F3C` | 強調。1枚に1か所だけ（枠 `strokeWidth='3'` か見出し帯） |
| `MB` 水色 | `#5B9BD5` | 要点のアイコン |
| `LB` 薄い青 | `#DDE8F4` | Point 帯、箱の中の項目 |
| `G` グレー | `#F2F2F2` | 行ラベル、入力の箱、表のセル |
| `K` 黒 | `#1A1A1A` | 本文の文字、見出し下の線 |
| `S` 灰色文字 | `#595959` | 補足、ページ番号 |
| `W` 白 | `#FFFFFF` | 背景、濃い地の上の文字 |

`fontFamily='Noto Sans JP, Hiragino Sans, sans-serif'` を `<svg>` に付ける。

## 配置（960×540）

- 左右の余白 48。本文の幅 864（x=48〜912）。
- 見出し：`x='48' y='60' fontSize='30' fontWeight='700'`、すぐ下に `<rect x='48' y='76' width='864' height='4' fill={K}/>`。
- 本文は y=100 から y≈420 まで。下部の要点・Point・結果ボックスは y≈424〜512。
- ページ番号：`x='936' y='534' textAnchor='end' fontSize='13' fill={S}`。表紙には付けない。
- 文字の大きさ：見出し 30、箱の見出し 20、本文 17〜19、補足 14〜16、大きな数字 24〜34。13未満にしない。

## 部品

| 部品 | 形 |
| --- | --- |
| 表紙 | 左端に幅24の紺の帯。上に小見出し（22, 紺）、題名2行（46, 太字）、黒線、補足2行（20, 灰）、日付のグレーのタグ |
| 箱（処理） | 角丸 8〜10。入力・中間は `G` 塗り、主処理は紺塗り＋白文字、注目は白地＋赤枠 |
| 枠付きグループ | 紺の枠線 2.5 と、上に紺の見出し帯（高さ46、白文字20） |
| 行ラベル＋ピル | 左に `G` の行（高さ56）、右に紺のピル（rx=28）で値を白太字24。横に補足（14, 灰） |
| 表 | 見出し行は紺地に白文字18、行見出しは `D` 地に白太字、セルは `G` 地 |
| 要点 | 左に Lucide `lightbulb`（`MB`）、右に1〜2行の本文18 |
| Point 帯 | `LB` の帯（rx=8）、左に「Point」（紺, 太字）、続けて1行 |
| 結果ボックス | 紺地 256×80（rx=14）、左上にラベル16、右下に数字34。左に Lucide `arrow-big-right`（紺塗り）を置いて要点から結ぶ |
| 流れの矢印 | 箱の間は Lucide `arrow-big-right` か `chevron-down`（紺塗り） |

## 書き方の注意

- 文字は折り返されない。1行の文字数を箱の幅から数える（17px の日本語は1文字およそ17）。長ければ行を分けるか箱を広げる。
- 同じ種類の箱は同じ塗りにする。色に意味を持たせたら、見出しか要点で説明する。
- 影・グラデーションは使わない。
