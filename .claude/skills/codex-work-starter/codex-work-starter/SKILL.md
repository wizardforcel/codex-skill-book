# Codex Work Starter

Start with one real task, prove it works manually, then make it reusable.

Read [references/prompts.md](references/prompts.md) for the complete prompt library.

## Setup

1. Write short custom instructions describing the user's role, preferred language, candor, formatting, and privacy boundaries.
2. Connect only the apps required for the task.
3. Use one project for one major responsibility and one long thread for one continuing task.
4. Create a dedicated chief-of-staff thread for cross-app work.

## Safety boundary

- Reading, organizing, and drafting can proceed within the authorized scope.
- Sending, unsubscribing, inviting, deleting, publishing, purchasing, or changing permissions must stop for human confirmation unless the user explicitly authorizes that exact action.
- Keep useful source links while removing unnecessary sensitive detail.
- Never expose passwords, identity numbers, payment data, or secret keys in a report or recording.

## Workflow

1. Run the prompt manually.
2. Inspect source coverage and the result.
3. Correct tone, omissions, and privacy leaks.
4. Save the successful method as a prompt or skill.
5. Only then turn it into a recurring task.

## Verification

For each task, report what was read, what changed, what was not changed, how the result was checked, and which important action still awaits confirmation.
