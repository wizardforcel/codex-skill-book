# Codex真实工作提示词库

## 自定义指令

```text
我是【职业/身份】。我经常要处理【邮件、会议、表格、文档等】。我不是程序员。

帮我干活时：
- 用大白话讲清结果；
- 该提醒就直接提醒，不要只顺着我；
- 除了真正代码，不用代码块堆正文；
- 写邮件和报告时去掉空话、套话、过多破折号和生硬AI腔；
- 不在结果里暴露身份号码、电话、住址、付款信息或密钥；
- 涉及发送、退订、建会、删除、发布、付款时先停下来让我确认。
```


```text

```


```text
找出未来7天所有会议，按时间列出，并标出需要提前准备资料的会议。保留日历入口，只做整理。
```

```text
针对【会议名称】做会前准备：读取我授权的相关邮件和文档，先问我最想推动的结果，再生成议程、关键问题、风险点和会后待办模板。
```

## 学生论文与课堂展示

```text
根据这个题目和我提供的参考资料做论文准备：
1. 标出资料来源和研究对象；
2. 区分不同观点；
3. 列论文大纲和每部分需要的证据；
4. 标出仍需补查的事实；
5. 生成课堂展示初稿。

不要捏造文献，不要代替我提交最终作业。
```

## 每周简报

```text
先手动生成一次本周工作简报：
1. 过去7天最该跟进的邮件；
2. 未来一周的会议与准备事项；
3. 尚未完成的待办；
4. 本周最重要的3件事。

保留来源入口，不发送、不退订、不建会。等我确认手动结果稳定后，再讨论是否设为每周一执行。
```
