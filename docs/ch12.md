## 12.1 Skill 不能替你做的事

### 简介

`grill-me`（需求澄清的反面参照）+ 第 12、13 章领域 Skill `grill-me` 逼你想清楚需求，但它不能替你想；因子是否有经济逻辑、命理解读是否越界，Skill 无法替你回答。这一节用这些 Skill 作为反面镜子，让读者把前面十三章建立的“Skill 能力感”收敛回“判断力仍然在你手里”。

什么叫“反面镜子”？就是 grill-me 不会给你答案，它只会问你问题，逼你自己想清楚。这就好比一个好的老师，不会直接给你答案，而是问你一堆问题，让你自己发现自己哪里没想清楚。

## 12.2 从使用 Skill 到设计自己的 SOP

### 简介

`skill-creator`（内置） 第 1 章用 `skill-creator` 是为了理解机制；到这里，读者已经走过了十一个场景，有了“什么工作流值得固化”的直觉。收束原则：一个 Skill 只做一件事，描述前载触发词，装上大量技能之前先确认每一个都有明确的触发边界。

什么叫“固化 SOP”？就是把你反复做的某件事，变成一个固定的流程，以后每次都按这个流程来，不用每次都重新想怎么做。`skill-creator` 就是帮你把 SOP 变成一个 Skill，这样以后你只需要说一句话，Skill 就会按固定的流程帮你处理。

# csv-check-sop

对 CSV 文件进行数据质量诊断：检查列名规范性、空值率、异常值分布，出检查报告后再决定后续清洗步骤。

## 触发方式

- 隐式触发：输入“帮我检查一下这个 CSV 文件的数据质量”“这个 CSV 有没有问题”等类似表述
- 显式调用：`$csv-check-sop`

# scripts/csv_check.py

```python
#!/usr/bin/env python3
"""csv-check-sop：CSV 数据质量基础检查。"""

import sys
from pathlib import Path

import pandas as pd


def check_csv(csv_path: Path) -> dict:
    """执行三项基础检查：列名、空值率、异常值分布。"""
    df = pd.read_csv(csv_path)

    # 1. 列名规范性检查
    col_issues = []
    for col in df.columns:
        if not col.isidentifier() or " " in col:
            col_issues.append(col)

    # 2. 空值率
    missing_rate = {col: float(df[col].isna().mean()) for col in df.columns}

    # 3. 数值列异常值分布（使用 IQR 规则）
    numeric_cols = df.select_dtypes(include="number").columns.tolist()
    outliers = {}
    for col in numeric_cols:
        q1 = df[col].quantile(0.25)
        q3 = df[col].quantile(0.75)
        iqr = q3 - q1
        lower = q1 - 1.5 * iqr
        upper = q3 + 1.5 * iqr
        outlier_count = int(((df[col] < lower) | (df[col] > upper)).sum())
        outliers[col] = outlier_count

    return {
        "rows": len(df),
        "columns": list(df.columns),
        "column_name_issues": col_issues,
        "missing_rate": missing_rate,
        "outlier_counts": outliers,
    }


if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法：python scripts/csv_check.py <csv文件路径>")
        sys.exit(1)

    csv_path = Path(sys.argv[1])
    if not csv_path.exists():
        print(f"未找到文件：{csv_path}")
        sys.exit(1)

    result = check_csv(csv_path)
    print("=== CSV 数据质量检查报告 ===")
    print(f"行数：{result['rows']}")
    print(f"列数：{len(result['columns'])}")
    print(f"列名规范性问题：{result['column_name_issues'] if result['column_name_issues'] else '无'}")
    print("空值率：")
    for col, rate in result["missing_rate"].items():
        print(f"  - {col}: {rate:.2%}")
    print("异常值计数（IQR 规则）：")
    for col, count in result["outlier_counts"].items():
        print(f"  - {col}: {count}")
    print("\n检查完成。请根据报告决定是否需要清洗、填充或进一步分析。")
```
