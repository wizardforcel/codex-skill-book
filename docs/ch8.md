# 第8章 编写论文

写论文最忌讳一上来就写：类型没定、章节没排、文献没核，写出来的东西大概率要重来。这一章的两个 Skill 一个管“中文优先的学术写作流程”，一个管“数学建模竞赛论文的格式合规与交付安全”。它们的共同点是把“先确认再写作”“先检查再交付”固化成流程，而不是让你把一段提示词扔给模型的运气游戏。写论文最怕一边写一边改类型和工作量，所以先把类型与结构确认清楚再动笔，返工率会低很多，心态也稳。

## 8.1 中文优先的学术写作与学位论文

### 简介

`research-writing-skill` 是中文优先的学术写作 Skill，覆盖头脑风暴、章节写作、文献综述、Python 图表和 LaTeX 输出，支持“帮我写毕业论文”这类隐式触发。它的价值在于把中文学术写作的规范内置到生成过程中，而不是先出英文再翻译。

中文优先是什么意思？就是直接用中文写论文，而不是先用英文写一遍，再翻译成中文。很多 AI 习惯于用英文思考，如果你让它写中文学术论文，它可能先写英文再翻译，结果翻译出来的中文读起来很别扭。`research-writing-skill` 就是避免这个问题，直接从中文学术规范出发。

### 调用记录

我们先让模型演示怎么写毕业论文引言：

> **提示词**：给出“帮我写一篇深度学习图像分割的毕业论文引言，约 500 字”，观察它是否先追问论文类型、学科、研究背景、方法，而不是直接生成一段泛泛的引言。

> **提示词**：论文类型：学术学位硕士论文；学科：计算机科学与技术；研究背景：医学影像（脑肿瘤分割）；方法：基于 U-Net 的改进模型；创新点：引入注意力机制和残差连接。

> # 第一章 绪论
>
> ## 1.1 研究背景与意义
>
> 随着医学影像技术的飞速发展，磁共振成像（MRI）已成为脑肿瘤诊断的重要手段。准确、自动化的脑肿瘤图像分割对于肿瘤体积测量、手术规划及治疗效果评估具有重要的临床价值。然而，传统的图像分割方法多依赖于人工阅片或半自动化工具，效率低且受主观因素影响较大。
>
> 近年来，深度学习在计算机视觉领域取得了突破性进展，全卷积网络（FCN）及其变体为医学影像分割提供了新的思路。其中，U-Net 及其改进模型在医学图像分割任务中表现出色，但脑肿瘤边界模糊、内部异质性高等问题仍待解决。
>
> ## 1.2 国内外研究现状
>
> 国内外学者已提出多种基于深度学习的图像分割方法，如 DeepLabV3+、SegFormer 等。然而，现有方法在处理小目标、边界不清晰的医学图像时，分割精度仍有提升空间。
>
> ## 1.3 本文研究内容与创新点
>
> 本文针对脑肿瘤医学影像分割问题，提出一种基于 U-Net 的改进模型，引入注意力机制和残差连接，提升分割精度。主要研究内容包括：(1) 构建基于 U-Net 的基础分割网络；(2) 引入注意力机制增强网络对关键特征区域的关注；(3) 采用残差连接缓解梯度消失问题；(4) 在公开医学影像数据集上进行实验验证。
>
> 本文的其余章节安排如下：第二章介绍相关理论基础；第三章详细阐述所提方法；第四章展示实验结果与分析；第五章总结全文并展望未来工作。

### 总结

- `research-writing-skill` 是中文优先的学术写作 Skill，直接用中文写，不先出英文再翻译。
- 写毕业论文引言前先追问论文类型、学科、研究背景、方法和创新点，不直接生成泛泛的引言。
- 生成的引言符合中文学术写作规范，有明确的研究背景、现状综述和创新点阐述。

## 8.2 数学建模竞赛论文的模板与检查

### 简介

`mathmodel-latex-skill` 面向 MCM/ICM、CUMCM 的 LaTeX 论文 Skill，解决竞赛特有的“格式合规 + 交付安全”问题，包含 LaTeX 编译预检、匿名检查、引用/关键词校验和 CUMCM 优秀论文风格规则。

数学建模竞赛是什么？就是给你一个实际问题，让你在有限时间内建立数学模型、求解、写论文。这类竞赛对论文格式要求很严格，格式不对可能直接被淘汰。`mathmodel-latex-skill` 就是帮你把论文格式弄对，避免因为格式问题丢分。

### 调用记录

我们先让模型生成模板并检查引用：

> **提示词**：生成空的竞赛论文模板，故意留一个 `\cite{missing}`，执行引用检查，确认它报出未定义引用，而不是让 PDF 编译静默通过。

> **Codex 输出**

## 8.3 从零生成骨架与可编译初稿

端到端链路是什么意思？就是从开始到结束的一整套流程，中间不需要人工插手。从研究主题开始，自动生成章节骨架，再生成引用格式，最后输出 LaTeX 文件，整个过程都由 Skill 来完成。
