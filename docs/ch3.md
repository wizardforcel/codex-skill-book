# 第3章 制作视频

视频是重交付物：一个三分钟的口播，光“把停顿和口误剪掉”就可能占掉整条制作链一半的时间。这一章介绍两个视频类 Skill，一个负责“粗剪 + 字幕”这条最耗时的链路，一个负责“配乐卡点成片”的风格化包装。

你会看到，它们不是替代剪辑软件，而是把剪辑软件里那些“可被规则描述”的动作交给代码去做，让 AI 先给你一份能审阅的清单。视频制作是最容易直奔结果去、也最容易返工的过程，这两个 Skill 分别负责素材清洗和风格包装，正好是一前一后两道工序。

## 3.1 口播视频的自动粗剪与字幕

### 简介

`videocut-skills` 专为口播视频设计：静音检测阈值可调，语义理解识别重说和卡顿，重复句检测按“相邻句开头≥5字相同”删前保后，输出 `edited.mp4` 和 `edited.srt`。核心价值是把“粗剪 + 字幕”这条最耗时的链路交给 Skill，并给出可逐条审阅的删除清单。

安装方式：

```powershell
git clone https://github.com/Ceeon/videocut-skills.git ~/.codex/skills/videocut
```

> 2. ✅ 口误 1 (00:20.1-00:22.0)

>

>

### 总结

- `videocut-skills` 专为口播视频设计，静音检测阈值可调，语义理解识别重说和卡顿。
- 重复句检测按“相邻句开头≥5字相同”删前保后，输出 `edited.mp4` 和 `edited.srt`。
- 核心价值是把“粗剪 + 字幕”这条最耗时的链路交给 Skill，并给出可逐条审阅的删除清单。
- 用户只确认前 3 条删除建议，Skill 按照确认的建议执行剪辑。

## 3.3 从粗剪到包装的衔接

### 简介

粗剪 Skill 清洗素材，卡点 Skill 做风格化包装，两者覆盖视频生产链上不同的工序。衔接的关键是粗剪产物能否被卡点 Skill 直接接受为输入。

### 调用记录

我们先让模型验证两个 Skill 能否串联：

> **提示词**：把 3.1 产出的 edited.mp4 作为 3.2 的输入素材，让 match-cut 基于这段粗剪做 20 秒卡点版本，验证两个 Skill 能否串联。

> **Codex 输出**
>
> videocut-skills 负责口播视频的自动粗剪与字幕，输出 edited.mp4 和 edited.srt。match-cut 负责卡点转场与产品宣传片。两者覆盖视频生产链上不同的工序。
>
> 衔接的关键是粗剪产物能否被 match-cut 直接接受为输入。edited.mp4 是标准 MP4 格式，match-cut 可以直接读取作为输入素材，基于粗剪做 20 秒卡点版本。
>
> ### 粗剪到包装衔接
>
> #### 输入素材
>
> - 文件：edited.mp4（videocut-skills 产出的粗剪视频）
> - 时长：约 54 秒
> - 格式：MP4，H.264 编码
>
> #### match-cut 处理
>
> match-cut 接受 edited.mp4 作为输入，基于粗剪素材做 20 秒卡点版本：
> 1. 读取 edited.mp4，分析视频结构和音频节拍
> 2. 提取咖啡杯（或主体物体）作为匹配锚点
> 3. 按 20 秒卡点节拍重新编辑，每秒一刀，切换不同场景背景
> 4. 保留咖啡杯的形状和动作延续，实现匹配剪辑效果
> 5. 输出 20 秒卡点版本
>
> #### 串联验证
>
> videocut-skills 输出的 edited.mp4 能够被 match-cut 直接接受为输入，无需格式转换。两个 Skill 能够串联：粗剪清洗素材 → 卡点包装成品。

### 总结

- 粗剪 Skill 清洗素材，卡点 Skill 做风格化包装，两者覆盖视频生产链上不同的工序。
- 衔接的关键是粗剪产物能否被卡点 Skill 直接接受为输入。
- `videocut-skills` 输出的 `edited.mp4` 能够被 `match-cut` 直接接受为输入，无需格式转换，两个 Skill 可以串联。

---

本章介绍了两个视频类 Skill，真正值得带走的是下面几条：

- `videocut-skills` 负责“粗剪 + 字幕”，给出可逐条审阅的删除清单，用户确认后再执行剪辑。
- `match-cut` 负责“卡点转场与产品宣传片”，先给方案再渲染，不直接输出成片。
- 两个 Skill 可以串联：粗剪产物 `edited.mp4` 直接作为卡点 Skill 的输入素材。
- 视频制作是最容易直奔结果去、也最容易返工的过程，Skill 把“可被规则描述”的动作交给代码去做，减少返工。
