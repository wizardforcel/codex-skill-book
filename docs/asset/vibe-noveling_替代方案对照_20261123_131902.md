# 本地工作流初始化

## 第一步：项目初始化

创建项目目录结构：
```
我的网文项目/
├── project.yaml          # 项目设定（书名、类型、目标读者、更新频率）
├── characters.yaml       # 人物设定
├── world_building.yaml   # 世界观设定
├── outline.yaml          # 大纲规划
├── chapters/             # 章节目录（空，尚未写入）
└── state.json            # 写作状态文件
```

## 第二步：创作设定确认

请确认以下设定：
1. 书名：（待填写）
2. 类型：经营流 / 都市 / 玄幻 / 科幻 等
3. 目标读者：青少年 / 中年读者等
4. 主要人物：主角、配角、反派
5. 世界观：现代都市 / 异界玄幻等
6. 大纲章数：预计写多少章

## 第三步：大纲规划

在确认创作设定后，生成大纲规划（按 50 章分阶段），然后才进入章节写作。
