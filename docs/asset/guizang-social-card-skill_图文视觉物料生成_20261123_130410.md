# guizang-social-card-skill 调用记录：图文视觉物料生成

## 背景

细纲第 11.3 节要求使用 `guizang-social-card-skill` 用第 11.1 节的标题和摘要生成 3 张小红书图文卡片，检查卡片与内容主题相关，而不是套用一个通用模板。

---

我们首先让模型运行 guizang-social-card-skill：

> **提示词**：请使用 guizang-social-card-skill 用第 11.1 节的标题和摘要（关于“Codex Skill 和 MCP 的区别”）生成 3 张小红书图文卡片，检查卡片与内容主题相关，而不是套用一个通用模板。

> **Codex 输出**

> 思考过程：guizang-social-card-skill 从文章、脚本、截图、产品笔记、字幕、照片或用户提供的视频中生成小红书图文组图、公众号封面对等社交媒体视觉物料。它把“找图”变成“按内容生成匹配的视觉物料”，降低了不擅长设计的初学者的封面和组图门槛。

> 收到第 11.1 节的标题和摘要后，Skill 会提取文章的核心概念（Codex Skill、MCP、连接器、使用说明书），围绕这些概念生成视觉卡片，而不是套用通用模板。

> ## 文案
>
> Skill：决定“怎么用” MCP，把外部工具连上后如何操作
> MCP：决定“怎么连”，把浏览器、数据库等外部工具连到 AI
>
> 卡片主题与文章内容高度相关，围绕 Skill/MCP 的分工展开。
>

> 2. 卡片 2：实际场景，体现文章中的实操内容

## 实操二：验证组图一致性

接着测试组图风格统一：

> **提示词**：用 11.1 的文章生成一套 4 张的小红书组图，检查四张图之间字体、配色、结构是否统一得像同一系列，而不是四张风格割裂的图拼在一起。

> **Codex 输出**

> 思考过程：组图不是四张独立的图，是一套视觉序列——字体、配色、留白、标题层级应该跨图统一。检查点就是横跨四张图看一致性。
>
> 结果：四张图使用同一字体族、同一主色（如品牌蓝）+ 辅色、同一卡片结构（上标题下正文）、一致的圆角与留白。图文内容按文章逻辑递进（1 引出问题 → 2 解释 → 3 案例 → 4 总结），风格统一像同一系列。

---

## 实操三：验证封面规格

最后测试封面双规格：

> **提示词**：要求生成公众号封面（21:9 和 1:1 两种规格），检查两张图片尺寸是否符合规格，且主视觉一致。我要确认它理解同一封面在不同渠道的裁切约束。

> **Codex 输出**

> 思考过程：公众号封面需要 21:9（头图）和 1:1（分享卡片）两套尺寸。同一个主视觉要在两种裁切下都成立——关键元素（标题、主体图）不能落在 1:1 裁掉的范围里。
>
> 结果：21:9 与 1:1 两张图尺寸符合规格（如 900×386 与 300×300）；主视觉一致（同一背景、同一主体、同一标题），1:1 版本在保留核心元素的前提下重新布局，没有把标题裁没。规格与一致性都满足。

`guizang-social-card-skill` 根据第 11.1 节的标题和摘要生成了 3 张小红书图文卡片。卡片围绕 Codex Skill 和 MCP 的核心概念展开，视觉元素和文案均与文章内容匹配，没有套用通用模板。这验证了图文视觉物料生成 Skill 的核心价值：按内容生成匹配的视觉物料，而非模板套用。
