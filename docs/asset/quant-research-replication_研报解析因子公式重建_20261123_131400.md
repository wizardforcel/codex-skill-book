# 研报解析结果

## 研报来源

- 标题：《基于动量反转的股票选股因子研究》
- 来源：公开量化研报
- 因子公式：动量因子 = (P_t / P_{t-12} - 1) × (1 - 反转调整系数)

## 因子公式重建

```python
def momentum_factor(prices, lookback=12, reversal_adj=0.5):
    """
    重建的动量因子公式：
    动量 = (当前价格 / 12个月前价格 - 1) × (1 - 反转调整系数)
    """
    momentum = (prices / prices.shift(lookback) - 1) * (1 - reversal_adj)
    return momentum
```
