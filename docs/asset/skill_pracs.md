# Skill - 实战练习清单

本文件从 `docs/asset/detail.md` 的细纲中按 **Skill** 重新组织，每个 Skill 出现一次，下方列出其在哪些章节/节中被使用，以及对应的「小实操」。可用于在写章前安装验证、练习触发和产出核对。

文末附录了“无专属 Skill”的节（纯运行时安装 / MCP 单独跑通 / 概念收束），供参考。

## data-analysis-skills

### 第 7.1 节 —— 表格数据的 EDA 与建模：Titanic
**小实操**：让 Codex 用 `safe-kaggle-mcp` 拉取 Titanic 训练集，再用 `data-analysis-skills` 做“生存率影响因素”EDA。要求先给出缺失率表和目标变量分布，再重点检查 `Sex`、`Pclass`、`Age` 与 `Survived` 的关系，并明确标注哪些结论是描述性统计、哪些只是相关而非因果。检查 HTML 报告每张图是否配有解读，以及是否声明了样本量和缺失处理方式。

### 第 7.2 节 —— 不平衡表格数据的审查与基线：Credit Card Fraud
**小实操**：让 Codex 先输出正类占比和特征缺失/量纲概况，再训练一个逻辑回归基线和一个带 `class_weight='balanced'` 的基线，同时报告 PR-AUC、precision、recall 和混淆矩阵，并明确回答：“如果只看 accuracy，这个模型会给人什么错觉？”检查报告是否指出 accuracy 在不平衡数据上的误导性，而不是给出一个 99.8% 的数字就结束。

### 第 7.3 节 —— 零售时序的趋势、季节性与回测：Rossmann Store Sales
**小实操**：选一家门店，让 Codex 先输出按周和按月的销售曲线，标出促销周和节假日附近的变化；再用 `Prophet_mcp` 做 6 周预测，明确给出训练截止日和回测区间。检查报告是否区分“拟合历史”和“预测未来”，以及是否在回测区间上计算误差，而不是只展示一条漂亮的全历史拟合线。

### 第 7.4 节 —— 多序列时序与层次结构：Walmart Store Sales Forecasting
**小实操**：让 Codex 选 3 家门店（总销量高、中、低各一家），分别输出周销售曲线和促销标记，比较它们的季节性是否一致；然后用 `Prophet_mcp` 对其中一条序列做预测，要求报告 MAPE 或 RMSE，并回答“这条序列的误差能否代表其他门店”。检查它是否明确拒绝用单条序列的结论覆盖全部门店。

### 第 8.2 节 —— 表格与数据报表：把 Excel 变成可解释的结论
**小实操**：找一张带缺失值、列名不规范的 CSV，先让 `data-analysis-skills` 分析。要求它在画图之前先输出缺失率、每列的类型推断和“它打算按什么业务视角组织报告”。如果它直接开始出图而没有确认受众，说明门禁没有生效。

## 附录：无专属 Skill 的节（运行时安装 / MCP 单独跑通 / 概念收束）

- **1.2 安装 Node.js**：无（运行时安装）。小实操：重新打开终端，运行 `node --version`、`npm --version`、`npx --version`；再运行 `npx cowsay "Codex ready"`，验证 `npx` 的按需执行能力。

- **1.4 安装 Codex Desktop**：无（桌面应用安装）。小实操：打开一个已有项目，要求 Codex“解释目录结构，不要修改任何文件”，验证只读审批边界生效。如果它未经提示就修改了文件，说明审批策略需要调整。
